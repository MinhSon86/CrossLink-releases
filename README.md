# CrossLink releases

Download the latest Windows installer or Android APK from [Releases](https://github.com/MinhSon86/CrossLink-releases/releases/latest).

This repository distributes compiled CrossLink packages. Source code is maintained separately.

CrossLink 0.3 and later can check this repository for updates inside the application. Windows upgrades in place and reopens after installation. Android uses the system package installer and requires user confirmation.

Each release includes a signed update manifest and SHA-256 checksums. CrossLink 0.2 users need to install version 0.3 manually once to enable future update checks.
